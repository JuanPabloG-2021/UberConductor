## Uso de IA

El equipo registra el uso de herramientas de inteligencia artificial en [docs/AI_LOG.md](docs/AI_LOG.md). Cada integrante debe añadir sus entradas desde su propia rama y subirlas a `main` mediante Pull Request. Para la entrega, exporta la bitácora a PDF y adjúntala en la plataforma.
